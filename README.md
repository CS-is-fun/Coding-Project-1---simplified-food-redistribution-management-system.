# Coding-Project-1---simplified-food-redistribution-management-system.
A coding project I have decided to do for fun to expand my understanding of coding. It is about a simplified food redistribution management system which is meant to simulate where surplus food should go, while considering expiry dates, demand, distance, capacity and priority, while creating an optimised and efficient redistribution plan.
In this project, I am hoping to add:
  businesses with surplus food,
  charities/food banks,
  different types of food,
  expiry dates,
  quantities,
  locations,
  charity demand,
  delivery constraints.
I have started with a project that seems relatively difficult to me and is way above the scale that I have coded thus far to challenge me to learn and perform computational thinking throughout this project.
